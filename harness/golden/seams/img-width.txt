# image width parse and serialization seam

Records parse node representation and serialized markdown for
plain, sized, aligned, inline, and linked images.

[plain-markdown-image] plain markdown image without width or height
  input: ![a](x.png)
  parsed: node=image attrs={"src":"x.png","alt":"a","title":null,"width":null,"height":null}
  serialized: ![a](x.png)

[html-img-width] HTML img with width attribute only
  input: <img src="x.png" width="200">
  parsed: node=image attrs={"src":"x.png","alt":null,"title":null,"width":"200","height":null}
  serialized: <img src="x.png" width="200">

[html-img-alt-width-height] HTML img with alt, width and height attributes
  input: <img src="x.png" alt="c" width="200" height="100">
  parsed: node=image attrs={"src":"x.png","alt":"c","title":null,"width":"200","height":"100"}
  serialized: <img src="x.png" alt="c" width="200" height="100">

[html-img-unmodeled-align] HTML img with unmodeled align attribute, must stay rawHtmlBlock
  input: <img src="x.png" align="left">
  parsed: node=rawHtmlBlock attrs={"html":"<img src=\"x.png\" align=\"left\">"}
  serialized: <img src="x.png" align="left">

[inline-img-paragraph] inline HTML img inside a paragraph, preserved as rawHtmlInline
  input: text <img src="x.png" width="200"> tail
  parsed: node=rawHtmlInline attrs={"html":"<img src=\"x.png\" width=\"200\">"}
  serialized: text <img src="x.png" width="200"> tail

[linked-img-with-width] linked image with width attribute, link mark preserved (#124)
  input: [<img src="a.png" width="200">](https://x)
  parsed: node=image attrs={"src":"a.png","alt":null,"title":null,"width":"200","height":null} marks=[link:{"href":"https://x","target":"_blank","rel":"noopener noreferrer nofollow","class":null,"title":null}]
  serialized: [<img src="a.png" width="200">](https://x)
